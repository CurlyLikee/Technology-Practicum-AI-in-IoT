# Лабораторна робота 13. Робот-розміновувач з AI-модулем безпеки

Роботизована платформа для виявлення та знешкодження вибухонебезпечних предметів на базі ESP32 з ультразвуковим далекоміром HC-SR04, 4 сервоприводами шасі та маніпулятора, Edge AI модулем оцінки ризику детонації, захисним блокуванням маніпулятора та веб-пультом дистанційного керування.

## Що робить система

- **Вимірювання дистанції:** Опитування далекоміра HC-SR04 кожні 400 мс з розрахунком відстані у діапазоні від 2 до 400 см.
- **AI-оцінка ризику детонації:** Розрахунок швидкості наближення, обчислення індексу ризику від 0 до 100% та автоматична класифікація 4 рівнів загрози і типу виявленого предмета.
- **Захисне блокування маніпулятора:** Автоматична заборона керування стрілою та клішнею при критичному рівні загрози з примусовим переведенням стріли у безпечне положення.
- **Керування ходовою частиною:** 4 напрямки руху через пару сервоприводів з танковою схемою розворотів та аварійною зупинкою при небезпечній близькості.
- **Керування маніпулятором:** Підйом та опускання стріли від 10 до 90 градусів, відкриття та закриття клішні для захоплення предметів, повернення у безпечне положення.
- **Оптична індикація загрози:** Червоний світлодіод з 4 режимами: безперервне світіння, швидке блимання, повільне блимання та вимкнений стан залежно від рівня небезпеки.
- **Веб-пульт керування:** Вбудований HTTP-сервер з панеллю телеметрії, кнопками керування шасі та маніпулятором, відображенням індексу ризику та SOP-протоколу у реальному часі. Підтримка клавіатури WASD.
- **Термінальне керування:** Обробка літерних команд з Serial Monitor з перевіркою дозволу від AI-модуля та табличне виведення діагностики кожні 1.5 секунди.

## Апаратна частина Wokwi

| Компонент | Підключення | Призначення |
|---|---|---|
| ESP32-DevKitC-V4 | — | Головний мікроконтролер системи |
| Ультразвуковий далекомір HC-SR04 | TRIG GPIO 5, ECHO GPIO 18, VCC 5V, GND | Вимірювання дистанції до об'єкта |
| Сервопривод клішні | PWM GPIO 16 | Відкриття та закриття захоплюючої клішні |
| Сервопривод стріли | PWM GPIO 4 | Підйом та опускання стріли маніпулятора |
| Сервопривод лівого борту | PWM GPIO 2 | Рух та розвороти лівого колеса шасі |
| Сервопривод правого борту | PWM GPIO 15 | Рух та розвороти правого колеса шасі |
| Червоний світлодіод | GPIO 21 через резистор 220 Ом | Оптична індикація рівня загрози |
| Макетна плата | — | Комутація ліній живлення та сигналів |

## Структура файлів

| Файл | Опис |

| `src/sketch.ino` | Основна логіка ESP32: далекомір, шасі, маніпулятор, веб-сервер, термінальні команди та діагностика |
| `src/ai_safety.h` | AI-модуль безпеки: розрахунок індексу ризику, класифікація загроз, блокування маніпулятора та контроль шасі |

| `libraries.txt` | Список залежностей та бібліотек для симулятора Wokwi |
| `wokwi.toml` | Файл налаштувань запуску симулятора Wokwi |

## Як запустити

1. Відкрити [симуляцію проєкту у Wokwi](https://wokwi.com/projects/475946640028382209) або середовищі PlatformIO.
2. Скомпілювати прошивку та завантажити її в мікроконтролер ESP32.
3. Відкрити Serial Monitor для спостереження за таблицею діагностики та журналом подій.
4. Перейти у браузері за адресою http://localhost:8180 для керування шасі та маніпулятором.
5. Змінювати дистанцію далекоміра HC-SR04 у симуляторі та спостерігати за зміною рівня загрози та блокуванням маніпулятора.
6. Використовувати клавіші WASD для шасі, U/J/K для стріли та O/C для клішні з терміналу.
