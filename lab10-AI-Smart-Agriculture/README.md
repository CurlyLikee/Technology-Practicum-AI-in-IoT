# Лабораторна робота 10. Розумна агросистема з AI-прогнозом

Розумна агросистема на базі мікроконтролера ESP32 з автоматичним поливом, двома датчиками вологості грунту, кліматичним сенсором DHT22, модулем визначення кислотності pH, Edge AI прогнозом висихання та потреби поливу, передачею даних через MQTT на брокер HiveMQ та веб-панеллю керування у реальному часі.

## Що робить система

- **Моніторинг мікроклімату та грунту:** Зчитування температури і вологості повітря цифровим сенсором DHT22, вимірювання вологості грунту одночасно двома типами датчиків для підвищення точності та визначення рівня кислотності субстрату аналоговим модулем pH.
- **Інтелектуальний рушій Edge AI:** Розрахунок дефіциту тиску водяної пари за формулою Магнуса, зважена оцінка вологості грунту за показниками двох датчиків у співвідношенні 70 до 30 відсотків, прогноз залишкової вологості через одну годину та обчислення індексу потреби поливу від нуля до ста з урахуванням кислотності.
- **Автоматичний полив:** Увімкнення водяного насоса через силове реле при зниженні вологості нижче порогового рівня або за рекомендацією AI-моделі з адаптивним розрахунком тривалості поливу, захисним обмеженням часу роботи та паузою між сесіями.
- **Температурний контроль вентиляції:** Автоматичне увімкнення вентилятора через друге силове реле при перевищенні температури понад 30 градусів Цельсія та вимкнення з гістерезисом два градуси для запобігання частому перемиканню.
- **Хмарна телеметрія MQTT:** Публікація одинадцяти параметрів вимірювань та прогнозів у форматі JSON до брокера HiveMQ кожні три секунди з підпискою на канал дистанційних команд для віддаленого керування насосом.
- **Інтелектуальний LLM-дайджест:** Періодичне формування розгорнутого аналітичного звіту з розділами мікроклімату, стану грунту та рекомендацій AI-моделі для зручного огляду оператором або подальшого оброблення великою мовною моделлю.
- **Веб-панель реального часу:** Інтерактивна HTML-сторінка з підключенням до MQTT-брокера через WebSocket, відображенням показників датчиків, графіками динаміки та кнопками дистанційного керування поливом.
- **Термінальний моніторинг:** Табличне виведення усіх контрольованих параметрів із журналом системних подій та часовими мітками синхронізованими з NTP-сервером.

## Апаратна частина Wokwi

| Компонент | Підключення | Призначення |
|---|---|---|
| ESP32-DevKitC-V4 | — | Головний мікроконтролер системи |
| Датчик клімату DHT22 | SDA GPIO 4, VCC 3V3, GND | Вимірювання температури та вологості повітря |
| Датчик вологості грунту | A0 до GPIO 34 | Визначення вологості грунту ємнісним методом |
| Повзунковий потенціометр 1 | SIG до GPIO 35 | Імітація другого датчика вологості грунту |
| Повзунковий потенціометр 2 | SIG до GPIO 32 | Імітація аналогового модуля визначення pH |
| Реле модуль 1 | IN GPIO 25 | Керування водяним насосом поливу |
| Реле модуль 2 | IN GPIO 26 | Керування вентилятором охолодження |
| Світлодіод індикаторний | GPIO 2 через резистор 220 Ом | Візуальна індикація активності насоса |
| Світлодіод індикаторний 2 | Через реле 2, резистор 220 Ом | Візуальна індикація роботи вентилятора |
| Макетна плата | — | Комутація ліній живлення та сигналів |

## Структура файлів

| Файл | Опис |
|---|---|
| `src/sketch.ino` | Основна логіка ESP32: датчики, керування поливом та вентиляцією, MQTT, NTP, журнал подій та термінальний вивід |
| `src/ai_model.h` | AI-рушій: розрахунок VPD, зважена оцінка вологості, прогноз висихання, індекс потреби поливу та LLM-дайджест |
| `dashboard.html` | Веб-панель з MQTT-підключенням через WebSocket, графіками та дистанційним керуванням |
| `diagram.json` | Схема підключення компонентів у симуляторі Wokwi |
| `soil-sensor.chip.c` | Вихідний код кастомного чіпа датчика вологості грунту на мові C для Wokwi |
| `soil-sensor.chip.json` | Опис сигналів та конфігурація кастомного чіпа датчика грунту |
| `soil-sensor.chip.wasm` | Бінарний модуль WebAssembly кастомного чіпа датчика грунту |
| `platformio.ini` | Конфігурація проєкту для середовища PlatformIO |
| `libraries.txt` | Список залежностей та бібліотек для симулятора Wokwi |
| `wokwi.toml` | Файл налаштувань запуску симулятора Wokwi |

## Як запустити

1. Відкрити [симуляцію проєкту у Wokwi](https://wokwi.com/projects/475244607960483841) або середовищі PlatformIO.
2. Скомпілювати прошивку та завантажити її в мікроконтролер ESP32.
3. Відкрити Serial Monitor для спостереження за підключенням до Wi-Fi, MQTT-брокера та таблицею телеметрії.
4. Змінювати повзунки потенціометрів для імітації вологості грунту та кислотності, а також регулювати параметри датчика DHT22 для перевірки автоматичного поливу та вентиляції.
5. Відкрити файл dashboard.html у браузері для перегляду показників у реальному часі та дистанційного керування поливом через MQTT.
