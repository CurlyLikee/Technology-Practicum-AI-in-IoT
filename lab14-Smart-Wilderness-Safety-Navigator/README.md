# Лабораторна робота 14. Подорожі (GPS-трекер/SOS + AI-аналітика)

Автономний експедиційний навігатор та аварійний маяк на базі мікроконтролера ESP32 з супутниковим модулем GPS NEO-6M, зовнішнім накопичувачем MicroSD, тактовою кнопкою тривоги, світлодіодною індикацією, звуковою сиреною на базі апаратного ШІМ, Edge AI оцінкою ризиків маршруту та вивантаженням телеметрії на хмарну платформу ThingSpeak.

## Що робить система

- **Супутникове позиціонування та фільтрація шуму:** Прийом навігаційних повідомлень від супутникового модуля GPS через апаратний послідовний порт, виділення географічних координат, висоти, швидкості та кількості активних супутників. Фільтрація дрейфу координат із порогом стаціонарного шуму антени 3.5 метри та експоненційне згладжування швидкості.
- **Edge AI класифікація рухової активності:** Аналіз поточної динаміки мандрівника та поділ пересування на 3 стани: відпочинок і стоянка при швидкості менше 1.2 км/год, штатна піша хода гірською стежкою до 6.0 км/год та швидке пересування бігом або транспортним засобом понад 6.0 км/год.
- **Геозонування та розрахунок ризику GeoRisk:** Моніторинг розташування туриста відносно трьох географічних секторів: безпечного базового табору з радіусом 70 метрів, ділянки гірського хребта з радіусом 200 метрів та небезпечної каньйонної зони з радіусом 300 метрів. Обчислення сукупного індексу ризику від 0 до 100% та автоматичне визначення 4 категорій загрози від мінімального ризику до критичного рівня.
- **Детекція нерухомості та підозри на травму:** Безперервний моніторинг тривалості стану спокою. При відсутності руху понад 60 секунд формується попереджувальне спостереження, а після 180 секунд знерухомлення у складній зоні активується статус підозри на травму або втрату свідомості.
- **Аварійний сигнал SOS та звуковий маяк:** Обробка тактової кнопки лиха з апаратним захистом від брязкоту контактів 80 мс. Активація двотонової звукової сирени на частотах 2400 Гц та 1800 Гц через апаратний таймер LEDC із захисним автоматичним вимкненням після 60 секунд для збереження заряду.
- **Багаторежимна світлодіодна сигналізація:** Адаптивне оптичне сповіщення на блакитному світлодіоді: швидкі спалахи з частотою 5 Гц під час тривоги або критичної небезпеки, ритмічне блимання з періодом 1 секунда при надійному супутниковому зв'язку та часті імпульси кожні 200 мс під час пошуку сигналу супутників.
- **Адаптивне збереження треку на MicroSD:** Запис фільтрованих експедиційних точок у табличний файл gps_log.csv за інтервалами: 8 секунд для стандартного переходу, 4 секунди у зонах підвищеної загрози та 2 секунди при надзвичайному стані або сигналі SOS.
- **Генерація мовного дайджесту для диспетчера:** Формування структурованого англомовного рядка LLM Explanation з оперативними даними сектору, швидкістю, балом ризику та рекомендаціями для диспетчерської пошуково-рятувальної служби.
- **Хмарна телеметрія ThingSpeak:** Передача 8 ключових параметрів маршруту на аналітичну платформу через захищене мережеве підключення кожні 15 секунд або миттєво під час увімкнення сигналу лиха.
- **Термінальна діагностика та дамп журналу:** Періодичне виведення структурованої таблиці параметрів кожні 4 секунди, реєстрація подій із системними часовими мітками та повне вивантаження вмісту файлу gps_log.csv при натисканні будь-якої клавіші в консолі або переході в аварійний стан.

## Апаратна частина Wokwi

| Компонент | Підключення | Призначення |
|---|---|---|
| ESP32-DevKitC-V4 | — | Головний мікроконтролер системи |
| Модуль GPS NEO-6M | TX до GPIO 16, RX до GPIO 17, VCC 5V, GND | Прийом супутникових координат та швидкості руху |
| Модуль картки пам'яті MicroSD SPI | CS GPIO 5, SCK GPIO 18, DO GPIO 19, DI GPIO 23, VCC 5V, GND | Енергонезалежне збереження табличного журналу точок маршруту |
| Тактова кнопка SOS | GPIO 4 з внутрішньою підтяжкою, другий контакт GND | Екстрена активація та ручне скасування режиму тривоги |
| П'єзоелектричний зумер | GPIO 25 через апаратний LEDC ШІМ, другий контакт GND | Звуковий акустичний маяк пошуково-рятувальної операції |
| Блакитний світлодіод | GPIO 21 через резистор 220 Ом, катод GND | Оптична індикація стану супутникової фіксації та тривоги |
| Резистор 220 Ом | Між GPIO 21 та анодом світлодіода | Струмообмежувальний опір світлодіодної лінії |
| Макетна плата | — | Комутація ліній живлення та сигналів |

## Структура файлів

| Файл | Опис |
|---|---|
| `src/sketch.ino` | Основна логіка ESP32: збір GPS, індикація, звуковий маяк, файлова система MicroSD, Wi-Fi, ThingSpeak та діагностика |
| `src/ai_tracker.h` | Edge AI модуль: геозонування, детекція знерухомлення і травми, розрахунок ризику GeoRisk та генератор дайджесту |
| `diagram.json` | Схема підключення компонентів у симуляторі Wokwi |

| `gps-neo6m.chip.json` | Опис сигналів та повзунка швидкості кастомного чіпа GPS |
| `gps-neo6m.chip.wasm` | Скомпільований бінарний модуль WebAssembly кастомного чіпа GPS |
| `gps_log.csv` | Приклад згенерованого табличного журналу експедиційного маршруту на карті MicroSD |
| `platformio.ini` | Конфігурація проєкту для середовища PlatformIO |
| `libraries.txt` | Список залежностей та бібліотек для симулятора Wokwi |
| `wokwi.toml` | Файл налаштувань запуску симулятора Wokwi |

## Як запустити

1. Відкрити [симуляцію проєкту у Wokwi](https://wokwi.com/projects/476578007825353729) або середовищі PlatformIO.
2. Скомпілювати прошивку та завантажити її в мікроконтролер ESP32.
3. Відкрити Serial Monitor для спостереження за діагностичною таблицею та системним журналом подій.
4. Змінювати повзунок швидкості на чіпі GPS у симуляторі від 0 до 120 км/год для перевірки класифікації ходи та бігу.
5. Спостерігати за автоматичною зміною активних геозон, зростанням балу GeoRisk та адаптацією інтервалу збереження на MicroSD.
6. Натиснути кнопку SOS на схемі для перевірки швидкого блимання світлодіода, звукового маяка на зумері та негайної передачі координат у хмару.
7. Надіслати будь-який символ у Serial Monitor для перегляду накопиченого журналу точок маршруту з картки пам'яті.
