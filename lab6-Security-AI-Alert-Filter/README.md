# Лабораторна робота 6. Безпека дому (AI-антифальш тривог)

Інтелектуальна система охоронної безпеки на базі ESP32 з багаторівневою фільтрацією хибних спрацьовувань за допомогою AI/евристичного класифікатора, адаптивними політиками чутливості та хмарною телеметрією.

## Що робить система

- **Фільтрація хибних тривог:** Класифікація подій на 4 класи — нормальний стан (NORMAL), апаратний шум/брязкіт сенсора (NOISE), рух домашніх тварин (PET) та реальне проникнення людини (HUMAN_INTRUSION). Рух тварин і шуми автоматично відхиляються без запуску тривоги.
- **Комплексний аналіз сенсорів:** Одночасне врахування стану геркона дверей, тривалості сигналу руху з PIR-сенсора, кількості імпульсів та затримки між відкриттям дверей і рухом.
- **Адаптивні політики безпеки:** Перемикання режимів чутливості системи (DAY — денний, NIGHT — нічний, AWAY — режим максимального контролю за відсутності господарів).
- **Світлодіодна та звукова індикація:** При підтвердженому вторгненні людини вмикається сирена та червоний світлодіод. Зелений світлодіод показує активний стан охорони, а синій світлодіод індикує відкриття дверей.
- **Хмарна телеметрія:** Періодичне вивантаження 5 параметрів безпеки (визначений клас загрози, рівень впевненості, стан дверей, тривалість руху та кількість імпульсів) на платформу ThingSpeak кожні 16 секунд.
- **Керування через термінал:** Підтримка текстових команд для постановки або зняття з охорони, вибору денного чи нічного режиму, а також для тестування різних сценаріїв спрацювання.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| PIR-датчик руху | GPIO 19 | Детекція присутності та тривалості активності |
| Геркон дверей (Switch) | GPIO 4 | Датчик відкриття дверей |
| Червоний LED | GPIO 16 | Індикатор тривоги вторгнення |
| Зелений LED | GPIO 17 | Індикатор активного стану охорони |
| Синій LED | GPIO 5 | Індикатор відкриття дверей |
| П'єзоелектричний зумер | GPIO 18 | Звукова сирена тривоги |
| 3x Резистори (220 Ом) | Послідовно з LED | Обмеження струму світлодіодів |
| Макетна плата | — | Комутація та макетування схеми |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основний код ESP32: зчитування сенсорів, реакція сигналізації, Wi-Fi, ThingSpeak, термінальні команди |
| `src/ai_filter.h` | AI-модуль: вектор ознак, класифікатор загроз та адаптивні часові політики безпеки |
| `diagram.json` | Схема з'єднань компонентів у Wokwi |
| `platformio.ini` | Конфігурація середовища PlatformIO |
| `wokwi.toml` | Налаштування симулятора Wokwi |

## Як запустити

1. Відкрити симуляцію проєкту у [Wokwi](https://wokwi.com) або PlatformIO.
2. Завантажити прошивку на ESP32 та відкрити Serial Monitor.
3. Вводити команди в термінал або взаємодіяти з перемикачем геркона та датчиком руху в симуляторі для перевірки відсікання хибних тривог.
