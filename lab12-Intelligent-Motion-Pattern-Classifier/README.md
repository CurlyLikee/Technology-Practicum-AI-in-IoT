# Лабораторна робота 12. Класифікатор руху з AI-аналізом

Інтелектуальний класифікатор рухових патернів на базі мікроконтролера ESP32 з шестиосьовим датчиком руху MPU6050, Edge AI класифікацією механічних станів у реальному часі, світлодіодною та звуковою індикацією тривоги, кнопкою ручного скидання та передачею телеметрії в хмарний сервіс Adafruit IO.

## Що робить система

- **Зчитування даних руху:** Безперервне опитування шестиосьового датчика MPU6050 по шині I2C з інтервалом 40 мілісекунд, отримання вектора прискорення по трьох осях та компенсація сили тяжіння для виділення динамічного прискорення.
- **Класифікація рухових патернів Edge AI:** Накопичення відліків у ковзному вікні з 25 зразків, обчислення статистичної дисперсії та пікової амплітуди, розпізнавання трьох класів стану: спокій, побутовий шум та тривожний удар з адаптивним розрахунком рівня достовірності для кожного класу.
- **Автоматична тривога:** При виявленні тривожного удару система активує стан небезпеки з миготливою сиреною та червоним світлодіодом. Автоматичне зняття тривоги відбувається після трьох секунд безперервного спокою.
- **Ручне скидання:** Натискання апаратної кнопки миттєво знімає тривогу, очищує буфер класифікатора та вимикає сирену.
- **Світлодіодна індикація:** Зелений світлодіод сигналізує про нормальний стан системи, а червоний вмикається при виявленні загрози.
- **Хмарна телеметрія Adafruit IO:** Асинхронна передача пікового прискорення, дисперсії та статусу тривоги на хмарну платформу Adafruit IO через захищене HTTPS-з'єднання у окремому потоці FreeRTOS кожні 10 секунд.
- **Термінальний моніторинг:** Виведення JSON-пакетів з міткою часу, значеннями прискорення по трьох осях, дисперсією, піком, визначеним класом, достовірністю та статусом тривоги кожні 500 мілісекунд.

## Апаратна частина Wokwi

| Компонент | Підключення | Призначення |
|---|---|---|
| ESP32-DevKitC-V4 | — | Головний мікроконтролер системи |
| Датчик руху MPU6050 | SDA GPIO 21, SCL GPIO 22, VCC 3V3, GND | Вимірювання прискорення по трьох осях |
| Зелений світлодіод | GPIO 18 через резистор 220 Ом | Індикація нормального стану системи |
| Червоний світлодіод | GPIO 19 через резистор 220 Ом | Індикація стану тривоги |
| П'єзоелектричний зумер | GPIO 23 з апаратним ШІМ | Звукова сирена при виявленні загрози |
| Тактова кнопка | GPIO 15 з внутрішньою підтяжкою | Ручне скидання стану тривоги |
| Макетна плата | — | Комутація ліній живлення та сигналів |

## Структура файлів

| Файл | Опис |
|---|---|
| `src/sketch.ino` | Основна логіка ESP32: опитування MPU6050, індикація, сирена, Wi-Fi, Adafruit IO та JSON-звіти в термінал |
| `src/ai_classifier.h` | AI-класифікатор: ковзне вікно, розрахунок дисперсії та піку, порогова класифікація трьох станів руху |
| `diagram.json` | Схема підключення компонентів у симуляторі Wokwi |
| `platformio.ini` | Конфігурація проєкту для середовища PlatformIO |
| `libraries.txt` | Список залежностей та бібліотек для симулятора Wokwi |
| `wokwi.toml` | Файл налаштувань запуску симулятора Wokwi |

## Як запустити

1. Відкрити [симуляцію проєкту у Wokwi](https://wokwi.com/projects/475883756241241089) або середовищі PlatformIO.
2. Скомпілювати прошивку та завантажити її в мікроконтролер ESP32.
3. Відкрити Serial Monitor для спостереження за JSON-пакетами телеметрії та статусом підключення до Wi-Fi.
4. Натискати на датчик MPU6050 у симуляторі для імітації ударів та вібрацій і спостерігати за зміною класу руху та реакцією індикаторів.
5. Натиснути кнопку для ручного скидання тривоги.
