# Лабораторна робота 17. Кухонний пристрій (ваги/таймер/термометр + AI)

Інтелектуальний кулінарний комплекс контролю маси та внутрішньої температури страви Smart Culinary Precision Assistant на базі мікроконтролера ESP32, цифрового термощупа DS18B20, аналогового імітатора тензодатчика кухонних ваг, символьного дисплея LCD 1602, 3 тактових кнопок керування, звукового зумера, бортового модуля адаптивного AI-таймера та хмарної аналітики кривої нагрівання у ThingSpeak.

## Що робить система

- **Зважування порції та фільтрація шуму:** Неблокуюче опитування аналогового каналу маси кожні 300 мілісекунд із масштабуванням у діапазон від 50 до 2000 грамів та експоненційним згладжуванням з ваговими коефіцієнтами 0.8 і 0.2.
- **Контроль внутрішньої температури страви:** Цифрове опитування термощупа DS18B20 по шині OneWire з валідацією показників у межах від -40.0 до 150.0 градусів Цельсія.
- **Автоматична AI-рекомендація режиму за вагою:** Клас CulinaryAiChef аналізує поточну масу продукту та рекомендує оптимальну програму: для порцій до 450 грамів - режим стейка STEAK з цільовою температурою 65.0 градусів, від 450 до 1200 грамів - режим птиці POULTRY з нормою 75.0 градусів, а понад 1200 грамів - режим випічки BAKING з нормою 90.0 градусів.
- **Оцінка теплової динаміки прогрівання:** Кожні 500 мілісекунд модуль штучного інтелекту обчислює приріст температури, визначає градієнт швидкості нагрівання у градусах за хвилину з обмеженням пікових стрибків на рівні 35.0 градусів за хвилину та згладжує його з вагами 0.7 і 0.3.
- **Адаптивний перерахунок таймера та готовності:** Динамічне коригування залишкового часу зворотного відліку у секундах як добутку залишкової різниці температур, коефіцієнта 12.0, вагового множника теплоємності 0.35 + маса / 1000 * 0.85 та оберненого множника швидкості нагрівання 6.0 / швидкість + 1.5, а також обчислення ступеня готовності від 0 до 100%.
- **Чотирирівнева класифікація стадій та LLM-поради:** Автоматичний розподіл процесу на 4 стадії STAGE_STANDBY, STAGE_HEATING, STAGE_READY та STAGE_OVERHEAT при перевищенні цільової температури на 8.0 градусів і більше з генерацією контекстних підказок LLM GUIDE для кухаря.
- **Керування програмами та таймером:** Опитування 3 тактових кнопок Mode, Start та Reset із програмним захистом від брязкоту контактів тривалістю 300 мілісекунд для циклічної зміни режиму, запуску або паузи відліку та скидання лічильника.
- **Локальна візуалізація на дисплеї:** Оновлення символьного екрана LCD 1602 кожні 400 мілісекунд із виведенням назви режиму, маси у грамах, поточної температури з точністю до 0.1 градуса, залишкового часу у хвилинах і секундах або сповіщень DISH READY та OVERHEAT.
- **Багатотональна звукова сигналізація LEDC:** Генерація 5 звукових сигналів через апаратний таймер LEDC без помилок ініціалізації: 1500 Гц на 40 мілісекунд при зміні режиму, 2000 Гц на 50 мілісекунд при старті або паузі, 1200 Гц на 40 мілісекунд при скиданні, 1800 Гц на 100 мілісекунд при готовності страви та 2400 Гц на 120 мілісекунд при перегріві.
- **Хмарна крива нагрівання ThingSpeak та термінал:** Передача 6 параметрів телеметрії у поля Field 1-Field 6 через HTTP GET кожні 15 секунд, ведення датованого журналу подій у форматі `[хвилини:секунди] [КАТЕГОРІЯ] повідомлення` та виведення таблиці Culinary Telemetry Table у консоль кожні 4 секунди.

## Апаратна частина Wokwi

| Компонент | Підключення | Призначення |
|---|---|---|
| ESP32-DevKitC-V4 | - | Головний мікроконтролер системи |
| Дисплей LCD 1602 I2C | SDA GPIO 21, SCL GPIO 22, VCC 3.3V, GND | Відображення кулінарного режиму, маси, температури, таймера та статусів |
| Цифровий термометр DS18B20 | DQ GPIO 14, VCC 3.3V, GND | Вимірювання внутрішньої температури страви по шині OneWire |
| Аналоговий потенціометр | SIG GPIO 34, VCC 3.3V, GND | Імітація тензодатчика кухонних ваг у діапазоні від 50 до 2000 грамів |
| П'єзоелектричний зумер | GPIO 27 через апаратний LEDC таймер, другий контакт GND | Звукове сповіщення про перемикання режимів, готовність страви та перегрів |
| Синя кнопка Mode | GPIO 32, другий контакт GND | Циклічне перемикання режимів POULTRY, STEAK та BAKING |
| Зелена кнопка Start | GPIO 33, другий контакт GND | Запуск та пауза адаптивного зворотного відліку таймера |
| Жовта кнопка Reset | GPIO 25, другий контакт GND | Скидання таймера, звукової тривоги та теплового лічильника |
| Макетна плата | - | Комутація ліній живлення 3.3V, 5V, землі та сигнальних провідників |

## Структура файлів

| Файл | Опис |
|---|---|
| `src/sketch.ino` | Основна логіка ESP32: опитування сенсорів маси і температури, кнопки, дисплей LCD 1602, зумер LEDC, Wi-Fi, ThingSpeak, журнал подій та таблиця телеметрії |
| `src/ai_chef.h` | Модуль кулінарного ШІ: режими, рекомендація за вагою, оцінка градієнта нагрівання, адаптивний перерахунок таймера, класифікація 4 стадій та поради LLM GUIDE |
| `diagram.json` | Схема підключення компонентів у симуляторі Wokwi |
| `platformio.ini` | Конфігурація проєкту для середовища PlatformIO |
| `libraries.txt` | Список залежностей та бібліотек для симулятора Wokwi |
| `wokwi.toml` | Файл налаштувань запуску симулятора Wokwi |

## Як запустити

1. Відкрити [симуляцію проєкту у Wokwi](https://wokwi.com/projects/481514728446901249) або проєкт у середовищі PlatformIO та за потреби вказати у `src/sketch.ino` власний ключ запису `TS_API_KEY` для каналу ThingSpeak.
2. Скомпілювати прошивку командою PlatformIO Build.
3. Відкрити `diagram.json` та запустити симулятор Wokwi.
4. Відкрити Serial Monitor для спостереження за журналом подій та таблицею Culinary Telemetry Table.
5. Повернути ручку потенціометра для встановлення маси порції від 50 до 2000 грамів та переконатися у миттєвому перерахунку прогнозованого часу таймера на дисплеї LCD 1602.
6. Натиснути синю кнопку Mode для вибору режиму POULTRY, STEAK або BAKING та зелену кнопку Start для запуску зворотного відліку.
7. Підвищити температуру на датчику DS18B20 до цільового порогу 65.0, 75.0 або 90.0 градусів для перевірки сповіщення DISH READY і до перевищення норми на 8.0 градусів для перевірки тривоги OVERHEAT.
8. Перевірити оновлення 6 графіків кривої нагрівання на панелі хмарного сервісу ThingSpeak.
