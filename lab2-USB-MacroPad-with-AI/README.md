# Лабораторна робота 2. Пристрій для комп'ютера (USB макропад з AI-підказками)

USB макропад на ESP32 з матрицею 4x4 кнопок, OLED-дисплеєм, трьома профілями макросів та AI-модулем контекстних підказок.

## Що робить система

- **16 макро-кнопок** (матриця 4x4) — зчитуються лише 8 GPIO пінами завдяки матричному скануванню.
- **3 профілі макросів**: General (буфер обміну, гучність), Coding (VS Code шорткати), Gaming (ігрові клавіші). Перемикання — утримання кнопки 9 протягом 2 секунд.
- **OLED-дисплей SSD1306** — відображає активний профіль та призначення кнопок.
- **AI-підказки** — модуль `ai_logic.h` аналізує частоту та патерни натискань, визначає контекст використання та генерує рекомендації кожні 10 секунд.
- **ThingSpeak** — вивантаження даних (натискання, профіль, AI-контекст) у хмару кожні 16 секунд.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| SSD1306 OLED | SDA: GPIO21, SCL: GPIO22 | Відображення профілю та макросів |
| 16x кнопок (4x4) | Rows: GPIO13, 12, 14, 27 / Cols: GPIO26, 25, 33, 32 | Матриця введення макросів |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основна прошивка: матричне сканування, дебаунс, профілі, OLED, Bluetooth HID, ThingSpeak |
| `src/ai_logic.h` | AI-модуль: розпізнавання патернів натискань, детекція контексту, генерація підказок |
| `test/test_debounce.ino` | Автоматизовані тести дебаунсу кнопок |
| `diagram.json` | Схема підключення компонентів у Wokwi |
| `platformio.ini` | Конфігурація збірки (ESP32, Adafruit SSD1306/GFX) |
| `wokwi.toml` | Прив'язка прошивки до симулятора |

## Як запустити

1. Відкрити проєкт у [Wokwi](https://wokwi.com) або PlatformIO
2. Зібрати та завантажити прошивку на ESP32
3. Натискати кнопки — команди виводяться в Serial Monitor
4. Для реального обладнання — підключити ESP32 по Bluetooth як клавіатуру
