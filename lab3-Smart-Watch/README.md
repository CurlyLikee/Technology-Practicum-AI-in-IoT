# Лабораторна робота 3. Смарт-годинник (класифікація активності TinyML)

Прототип смарт-годинника на базі ESP32 з класифікатором активності людини за допомогою TinyML, моніторингом пульсу, OLED-інтерфейсом та передачею даних у хмару.

## Що робить система

- **TinyML класифікація активності:** Аналіз даних з акселерометра та гіроскопа MPU6050 у буфері вибірок (розрахунок магнітуди, дисперсії та розмаху). Розпізнає 4 стани: спокій (IDLE), ходьба (WALKING), біг (RUNNING) та аварійний стан падіння (FALL).
- **Моніторинг серцевого ритму:** Інтеграція датчика пульсу MAX30102 для вимірювання та індикації частоти серцевих скорочень.
- **Багатоекранний інтерфейс:** OLED-дисплей SSD1306 з циклічним перемиканням 3 екранів тактовою кнопкою:
  1. Головний екран.
  2. Екран сирих сенсорних даних.
  3. Екран AI-рекомендацій енергозбереження.
- **Адаптивне енергозбереження:** Генерація підказок щодо оптимізації споживання енергії залежно від виявленого типу активності.
- **Хмарний зв'язок та бездротовий інтерфейс:** Періодична відправка даних до платформи ThingSpeak кожні 16 секунд, а також BLE-сервіс.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| MPU6050 | I2C (SDA: GPIO21, SCL: GPIO22) | 6-осьовий датчик руху (акселерометр + гіроскоп) |
| SSD1306 OLED | I2C (SDA: GPIO21, SCL: GPIO22) | Графічний дисплей інтерфейсу |
| MAX30102 | I2C (SDA: GPIO21, SCL: GPIO22), INT: GPIO34 | Сенсор пульсу та оксиметрії |
| Тактова кнопка | GPIO 15 | Перемикання екранів інтерфейсу |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основний код: опитування датчиків, перемикання екранів, Wi-Fi/ThingSpeak, BLE |
| `src/activity_classifier.h` | TinyML модуль: накопичення вибірок, розрахунок статистичних параметрів і класифікація |
| `max-30102.chip.json` | Кастомний чип емуляції датчика пульсу для симулятора Wokwi |
| `diagram.json` | Схема з'єднань компонентів у Wokwi |
| `platformio.ini` | Конфігурація середовища збірки та залежності бібліотек |
| `wokwi.toml` | Конфігурація запуску симулятора |

## Як запустити

1. Відкрити проєкт у [Wokwi](https://wokwi.com) або середовищі PlatformIO.
2. Зібрати та завантажити прошивку на ESP32.
3. У симуляторі змінювати параметри сенсорів (нахил, прискорення MPU6050, дані пульсу) для перевірки визначення активностей.
4. Кнопкою перемикати екрани для перегляду даних та рекомендацій.
