# Лабораторна робота 8. Медичний пристрій з AI-фільтрацією

Інтелектуальний медичний термометр навчального призначення на базі ESP32 з AI-фільтрацією технічних артефактів датчика, статистичним аналізом Z-score, класифікацією клінічного стану, керуванням реле охолодження та хмарною телеметрією.

## Що робить система

- **Вимірювання температури:** Безперервний моніторинг температури цифровим датчиком DS18B20 на шині OneWire щосекунди.
- **AI-фільтрація артефактів:** Детектор на основі ковзного вікна на 15 вимірів аналізує швидкість зміни температури та відсікає апаратні стрибки, що перевищують фізіологічну межу зміни температури тіла.
- **Статистичний контроль відхилень:** Розрахунок ковзного середнього і дисперсії за алгоритмом Z-score для виявлення статистичних аномалій у вимірах.
- **Класифікація клінічного стану:** Автоматичне визначення стану нормальної температури, субфебрилітету, лихоманки, переохолодження або технічного збою сенсора.
- **Керування охолодженням:** Автоматичне вмикання силового реле та червоного світлодіода при лихоманці з блокуванням хибного спрацьовування під час артефактів, а також підтримка ручного керування.
- **Відображення на дисплеї:** Виведення поточної температури, короткого коду стану пацієнта, відсотка аномальності та статусу реле на екран LCD 1602.
- **Хмарна телеметрія:** Вивантаження шести параметрів моніторингу до платформи ThingSpeak кожні 20 секунд.
- **Термінальне керування:** Підтримка текстових команд перегляду статистики, діагностики моделі, ручного перемикання реле, а також генерації шаблону інформованої згоди пацієнта та клінічного LLM-промпта.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| Датчик DS18B20 | GPIO 14 | Вимірювання температури |
| Резистор 4.7 кОм | Лінія даних датчика | Підтяжка шини OneWire до живлення |
| Дисплей LCD 1602 I2C | SDA GPIO 21, SCL GPIO 22 | Відображення температури та стану системи |
| Модуль реле | GPIO 25 | Керування навантаженням або охолодженням |
| Червоний LED | GPIO 2 | Індикатор активності реле |
| Резистор 220 Ом | Послідовно з LED | Обмеження струму світлодіода |
| Макетна плата | — | Комутація компонентів схеми |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основний код ESP32: зчитування сенсора, екран LCD, реле, Wi-Fi, ThingSpeak та термінал |
| `src/ai_logic.h` | AI-модуль: ковзне вікно, алгоритм Z-score, фільтр артефактів та класифікація станів |
| `diagram.json` | Схема з'єднань компонентів у Wokwi |
| `platformio.ini` | Конфігурація середовища PlatformIO |
| `libraries.txt` | Перелік бібліотек для симулятора Wokwi |
| `wokwi.toml` | Конфігурація запуску симулятора |

## Як запустити

1. Відкрити симуляцію проєкту у Wokwi або середовищі PlatformIO.
2. Завантажити прошивку на ESP32 та відкрити Serial Monitor.
3. Змінювати повзунок температури датчика DS18B20 для перевірки відсікання різких стрибків, визначення станів лихоманки та спрацьовування реле.
