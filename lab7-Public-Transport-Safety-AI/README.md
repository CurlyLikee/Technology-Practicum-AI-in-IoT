# Лабораторна робота 7. Безпека в громадському транспорті (AI-аналітика заповненості/CO₂)

Інтелектуальна система моніторингу безпеки та мікроклімату в салоні громадського транспорту на базі ESP32 з AI-оцінкою заповненості, контролем якості повітря за рівнем вуглекислого газу і летких органічних сполук та хмарною телеметрією.

## Що робить система

- **Підрахунок пасажирів:** Фіксація входів пасажирів за допомогою інфрачервоного датчика руху PIR із захистом від брязкоту та збереженням даних в енергонезалежній пам'яті EEPROM.
- **Контроль якості повітря:** Вимірювання концентрації вуглекислого газу CO₂, летких органічних речовин VOC, а також температури й вологості повітря датчиком DHT22.
- **AI-прогнозування заповненості:** Модуль штучного інтелекту виконує злиття даних лічильника руху та приросту концентрацій газів над адаптивним базовим рівнем, розраховує динаміку наростання CO₂ та розкид вимірювань для точної оцінки реальної кількості пасажирів.
- **Оцінка рівня ризику:** Визначення ступеня безпеки від нормального стану до помірного навантаження або критичного переповнення і задухи, а також виявлення аномальних стрибків показників.
- **Світлодіодна індикація:** Червоний світлодіод сигналізує про вхід пасажира коротким спалахом, а також попереджає про підвищений або критичний рівень загрози різною частотою блимання.
- **Хмарна телеметрія:** Періодичне вивантаження восьми параметрів телеметрії та структурованого пакета даних до платформи ThingSpeak кожні 16 секунд.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| PIR-датчик руху | GPIO 4 | Фіксація входу та переміщення пасажирів |
| Потенціометр CO₂ | GPIO 34 | Емуляція сенсора концентрації вуглекислого газу |
| Потенціометр VOC | GPIO 35 | Емуляція сенсора летких органічних сполук |
| Датчик DHT22 | GPIO 16 | Вимірювання температури та вологості |
| Червоний LED | GPIO 2 | Індикатор фіксації пасажирів та рівнів тривоги |
| Резистор 220 Ом | Послідовно з LED | Обмеження робочого струму світлодіода |
| Макетна плата | — | Комутація компонентів схеми |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основний код ESP32: зчитування сенсорів, індикація, пам'ять EEPROM, Wi-Fi та ThingSpeak |
| `include/ai_logic.h` | AI-модуль: адаптивний базовий рівень, тренд CO₂, об'єднання сенсорів і прогноз заповненості |
| `diagram.json` | Схема з'єднань компонентів у Wokwi |
| `platformio.ini` | Конфігурація середовища збірки PlatformIO |
| `wokwi.toml` | Конфігурація запуску симулятора Wokwi |

## Як запустити

1. Відкрити симуляцію проєкту у Wokwi або середовищі PlatformIO.
2. Завантажити прошивку на ESP32 та відкрити Serial Monitor.
3. Змінювати положення регуляторів концентрації газів та активувати датчик руху в симуляторі для спостереження за AI-прогнозом заповненості та зміною рівнів ризику.
