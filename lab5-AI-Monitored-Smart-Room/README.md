# Лабораторна робота 5. Індивідуальний проєкт, ч.2 (MVP/тести/демо + AI)

Розумна кімната на базі ESP32 з автоматичним керуванням мікрокліматом, освітленням, локальною сигналізацією та ML-моделлю виявлення аномалій.

## Що робить система

- **Керування освітленням:** Автоматичне ввімкнення світлодіода кімнати при темряві та фіксації руху. Вимкнення за таймером бездіяльності або при достатньому природному світлі.
- **Керування вентиляцією:** Автоматичний запуск вентилятора при підвищенні температури чи вологості понад комфортні межі, та вимкнення після повернення показників до норми.
- **Локальна сигналізація аномалій:** Звукове сповіщення зумером при аварійних подіях: екстремальному перегріві, сильному переохолодженні чи ризику затоплення приміщення.
- **Хмарний зв'язок:** Періодична відправка показників сенсорів та станів актуаторів до платформи ThingSpeak кожні 16 секунд.
- **AI-архітектура:** Python-модуль (`anomaly_detector.py`) для виявлення аномальних станів приміщення, розрахунку метрик якості та аналізу даних у реальному часі через ThingSpeak API.

## Апаратна частина (Wokwi)

| Компонент | Підключення | Призначення |
|-----------|-------------|-------------|
| ESP32-DevKitC-V4 | — | Мікроконтролер |
| DHT22 | GPIO 15 | Датчик температури та вологості |
| Фоторезистор LDR | GPIO 34 (ADC) | Вимірювання рівня освітленості |
| PIR-датчик | GPIO 17 | Детекція руху людини |
| Зелений LED | GPIO 18 | Освітлення кімнати |
| Червоний LED | GPIO 19 | Вентилятор охолодження |
| П'єзоелектричний зумер | GPIO 5 | Аварійна звукова сигналізація |

## Структура файлів

| Файл | Опис |
|------|------|
| `src/sketch.ino` | Основний код ESP32: зчитування сенсорів, логіка автоматизації, Wi-Fi та ThingSpeak |
| `anomaly_detector.py` | Модуль машинного навчання: тренування моделі, оцінка метрик та аналітика |
| `anomaly_plot.png` | Графік розподілу виявлених аномалій |
| `room_data.csv` | Набір даних вимірювань для навчання та тестування моделі |
| `diagram.json` | Схема з'єднань компонентів у Wokwi |
| `platformio.ini` | Конфігурація збірки PlatformIO |
| `wokwi.toml` | Конфігурація симулятора Wokwi |

## Як запустити

1. Відкрити симуляцію проєкту у [Wokwi](https://wokwi.com) або PlatformIO.
2. Завантажити прошивку на ESP32 та спостерігати роботу датчиків і актуаторів у Serial Monitor.
3. Запустити скрипт аналітики `python anomaly_detector.py` для навчання моделі та аналізу даних.
