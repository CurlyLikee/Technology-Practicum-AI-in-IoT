# Лабораторна робота 1. Розумні побутові пристрої (смарт-лампа/розетка з AI)

Адаптивна смарт-лампа на ESP32 з вбудованим TinyML-модулем, що прогнозує потребу в освітленні на основі звичок користувача.

## Що робить система

- **Автоматичний режим (AUTO):** Реагує на освітленість (LDR) та рух (PIR) — вмикає світло коли темно + є рух, вимикає по таймауту бездіяльності (8 с).
- **Режим ШІ (AI):** Онлайн-логістична регресія аналізує час доби (sin/cos кодування), день тижня, рух і темряву. Якщо ймовірність >= 0.62 — вмикає, <= 0.38 — вимикає.
- **Ручний режим (MANUAL):** Кнопка перемикає стан лампи. Коротке натискання — toggle, довге — зміна режиму по колу.
- **Донавчання:** Кожне ручне ввімкнення кнопкою автоматично оновлює ваги моделі (SGD, learning rate = 0.08), адаптуючи прогноз під реальні звички.
- **IoT-інтеграція:** Телеметрія передається на **Blynk** (мобільне керування, V0–V6) та **ThingSpeak** (хмарні графіки кожні 16 с).

## Апаратна частина (Wokwi)

| Компонент | Пін | Призначення |
|-----------|-----|-------------|
| Фоторезистор LDR | GPIO 34 (ADC) | Вимірювання освітленості |
| PIR-датчик руху | GPIO 26 | Детекція присутності |
| Тактова кнопка | GPIO 27 (PULL-UP) | Ручне керування та зміна режиму |
| Реле + LED | GPIO 19 | Комутація навантаження |

## Структура файлів

| Файл | Опис |
|------|------|
| `sketch.ino` | Основна програма: FSM, датчики, кнопка, Blynk, ThingSpeak, Serial CLI |
| `habit_ai.h` | TinyML-модуль: логістична регресія, SGD-навчання, EWMA-слоти по годинах, пояснення рішень |
| `diagram.json` | Схема підключення компонентів у Wokwi |
| `platformio.ini` | Конфігурація збірки (ESP32, Arduino, Blynk) |
| `wokwi.toml` | Прив'язка прошивки до симулятора |
| `libraries.txt` | Залежності для Wokwi |

## Як запустити

1. Відкрити проєкт у [Wokwi](https://wokwi.com) або PlatformIO
2. Зібрати та завантажити прошивку на ESP32
3. Команди Serial Monitor: `on`, `off`, `auto`, `manual`, `ai`, `learn`, `t HH:MM`
